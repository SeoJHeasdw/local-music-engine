# local-music-engine

Apple Silicon Mac에서 한국어 가사와 음악 지시를 받아 곡 후보를 생성하고,  
사람이 비교해 고른 후보의 문제 구간을 수정한 뒤 WAV로 내보내는 개인 제작 엔진.

> **상태:** 계획 단계. 구현·설치·모델 다운로드는 아직 수행하지 않았습니다.

---

## 목표 흐름

```
프로젝트 생성 → 전체 곡 후보 생성 → 비교 청취 → 후보 선택
→ 한 구간 재생성 → 연결부 확인 → WAV 내보내기 → 앱 재실행 후 프로젝트 복원
```

## 주요 기능 (첫 버전)

- 가사·스타일 지시·목표 길이·곡 구조를 저장하는 **프로젝트 관리**
- ACE-Step 어댑터를 통한 **전체 곡 생성**과 여러 seed 후보 관리
- 동일 위치를 오가며 들을 수 있는 **후보 비교**와 평가 메모
- 파일 무결성·피크·무음 등 기본 **자동 검사**
- 보컬 분리 + 한국어 ASR 기반 **가사 의심 구간 표시**
- 선택 구간의 **재생성**, 원본/수정본 비교, 채택 취소
- 원본 보존 **WAV 내보내기**와 모델·입력·검수 **이력 기록**

## 기술 스택

| 레이어 | 선택 |
|---|---|
| 생성기 | ACE-Step 1.5 (macOS MLX 경로) |
| Python | 3.12 |
| 앱 | Electron + TypeScript |
| 상태 저장 | SQLite + 파일 기반 artifact |
| 로컬 API | FastAPI (loopback only) |

## 구현 단계

| 단계 | 내용 |
|---|---|
| **P0** | 환경 확인, Apple Silicon 실제 생성 가능성 검증 |
| **P1** | CLI에서 프로젝트·후보 생성·선택·WAV 내보내기 |
| **P2** | 후보 비교 앱, 가사 의심 구간 UI |
| **P3** | 구간 편집, 첫 마일스톤 한국어 한 곡 완주 |
| **P4** | 측정 결과 기반 stem 믹싱·마스터링·LoRA 확장 |

## 주의 사항

- 모델 가중치·생성 오디오·개인 음성·로그는 Git에 포함하지 않습니다.
- 설치와 모델 다운로드 전에 목적과 예상 용량을 먼저 확인합니다.
- 자동 점수로 품질을 보증하지 않으며, 실제 청취로 판단합니다.
- 기존 `local-tts-engine` 환경과 데이터를 공유하거나 수정하지 않습니다.
