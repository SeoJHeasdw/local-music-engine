# 사람 청취 계약과 WAV 무결성 검사

자동 검사와 사람 청취는 서로 다른 기록이다. 자동 검사의 항목과 한계는 [자동 품질 검사](AUTO-QUALITY.md)에 있다.

## 사람 청취

후보마다 `humanReview.status`를 `unreviewed`, `listened`, `approved`, `rejected`로 기록한다. 자동 검사가 통과하고
추천을 받아도 기본값은 `unreviewed`다. 평점(1–5)과 메모는 청취 기록이며 자동 검사와 합산하지 않는다.
`recommendedCandidateId`(자동 추천)는 사람이 고른 `selectedCandidateId`를 바꾸지 않는다.

자동 검사가 보증하지 않으므로 들어서 확인하는 것:

- 발음의 정확성, 받아쓰기가 놓치거나 잘못 읽은 가사 누락·반복
- 보컬의 자연스러움, 곡 구조, 음악적 완성도와 취향
- 구간 수정(repaint) 시작·끝의 박자·음색·반주 연결
- 엔진이 보고한 템포·조성과 실제 소리의 일치

구간 수정은 선택 범위 앞뒤를 포함해 원본과 번갈아 듣는다. 자동 검사 탭이 "N–M초만 새로 만든 소리예요"라고
하면 그 밖은 고치기 전 버전과 샘플까지 같다([구간 수정](AUTO-QUALITY.md#구간-수정)). "엔진이 만든 그대로"라고
하면 선택 범위 밖도 달라졌을 수 있다. 마음에 들지 않으면 원본의 선택을 유지한다.

수정 도우미의 해석(LLM 또는 규칙), 자동 검사, 사람 청취는 따로 기록한다. 수정안이 실행됐다는 사실은 그 수정이
좋다는 뜻이 아니다.

## WAV 무결성 검사

모든 생성·수정·내보내기 결과는 실제 WAV를 PCM으로 디코딩해 기록한다.

- 파일 존재, SHA-256과 byte 수
- frame 수, sample rate, channel 수, sample width, 실제 길이와 요청 길이의 차이
- peak, RMS, 절대 진폭 `0.0001` 이하 sample 비율

헤더의 frame 수와 디코딩한 frame 수가 다르거나 마지막 frame이 잘리면 실패다. 8/16/24/32-bit 정수 PCM을
검사한다(8-bit unsigned 보정). IEEE float WAV는 지원하지 않으며 통과로 기록하지 않는다.

50 ms 창으로 모든 채널이 0.5초 이상 거의 무음인 구간(`silence_region`)과 peak `0.999` 이상 구간
(`peak_region`)을 실제 시간 범위와 함께 남긴다. 유형당 긴 구간 최대 32개를 표시하고 전체 수를 따로 기록한다.
앱의 **듣기** 버튼은 앞뒤 0.25초를 더해 반복 재생한다. peak `0.999` 이상, 무음 비율 `0.2` 초과, 길이 차이
`0.5초` 초과는 경고이며 의도된 쉼과 다이내믹을 결함으로 단정하지 않는다. 기존 후보의 과거 finding은
소급해서 덮어쓰지 않는다.
