# 품질 검사와 청취 계약

## 자동 검사가 보증하는 것

현재 QC는 실제 WAV 파일을 PCM으로 디코딩해 다음을 기록한다.

- 파일 존재와 비어 있지 않음
- frame 수, sample rate, channel 수, sample width, 실제 길이
- peak, RMS, 절대 진폭 `0.0001` 이하 sample 비율
- 요청 길이와 실제 길이 차이
- SHA-256과 byte 수

peak `0.999` 이상, near-digital-silence 비율 `0.2` 초과, 요청 길이 차이 `0.5초` 초과는
경고다. 의도된 쉼과 다이내믹을 결함으로 단정하지 않는다. 현재 ACE 출력의 -1 dB 정규화는
이미 생긴 왜곡을 고쳤다는 뜻이 아니다.

## 자동 검사가 보증하지 않는 것

- 한국어 발음·가사 누락·반복
- 보컬 자연스러움, 곡 구조, 음악적 선호
- repaint 시작/끝의 박자·음색·반주·음량 연결
- key/BPM/구조 추정 정확성
- Suno 또는 다른 서비스와의 품질 동등성

이 항목은 후보마다 `humanReview.status`를 `unreviewed`, `listened`, `approved`, `rejected`로
별도 기록한다. 자동 검사가 통과해도 기본값은 `unreviewed`다. 평점은 1–5 범위의 청취 메모일
뿐 자동 검사와 합산하지 않는다.

## repaint 검수

선택 범위 앞뒤 문맥을 포함해 원본과 수정본을 번갈아 듣는다. 첫 실측에서 5–9초 repaint가
0–5초와 9–15초도 바꿨으므로, 선택 범위 밖 파형이 동일하다고 가정하지 않는다. 길이 보존과
파일 무결성은 자동 확인하지만 연결감은 사람이 확인한다. 마음에 들지 않으면 원본 후보의 선택을
유지한다.

## 다음 품질 단계

보컬 분리기와 한국어 ASR은 코드·가중치 라이선스와 Apple Silicon 동작을 확인한 뒤 도입한다.
도입 전에는 가사 경고가 없다는 상태를 만들지 않는다. 같은 ASR의 재실행을 독립 판독 여러 개로
세지 않는다.
